# Customer_Behavior_Analysis
An end-to-end data analytics project that turns 3,900 retail customer records into business insights. It covers data cleaning, SQL analysis and an interactive dashboard.

---

## Project Overview

A retail business wants to understand **who its customers are, what they buy and what drives spending**. This project covers the full analyst workflow:

1. Load and explore the data in a Jupyter Notebook
2. Clean the data and engineer new features
3. Load it into PostgreSQL and answer business questions with SQL
4. Present the findings in an interactive Power BI dashboard

## Dataset

**3,900 customer records** with 18 columns:

| Group | Columns |
|---|---|
| Customer | Customer ID, Age, Gender, Location |

| Purchase | Purchase Amount (USD), Discount Applied, Promo Code Used, Payment Method, Shipping Type |
| Behaviour | Previous Purchases, Frequency of Purchases, Subscription Status, Review Rating |

## Project Workflow

### Data Loading and EDA (Jupyter Notebook)
- Loaded the CSV with `pandas`
- Inspected the data with `head()`, `info()` and `describe()`
- Checked for missing values with `isnull().sum()`

### Data Cleaning and Feature Engineering
- **Missing values:** Filled missing `Review Rating` values with the **median rating of each product category**
- **Column names:** Converted to lowercase `snake_case` (e.g. `purchase_amount_(usd)` → `purchase_amount`)
- **Age groups:** Created an `age_group` column (Young adult, Adult, Middle-aged, Senior) using quartile binning
- **Purchase frequency:** Converted text labels (Weekly, Monthly, etc.) into `purchase_frequency_days`
- **Redundant column:** Dropped `promo_code_used` after confirming it matched `discount_applied` in every row

### Loading into PostgreSQL
- Connected Python to a local PostgreSQL database using SQLAlchemy
- Wrote the cleaned data to a `customer` table with `df.to_sql()`

###  SQL Analysis
Ten business questions answered using aggregations, CTEs, subqueries, `CASE` statements and window functions (`ROW_NUMBER`):

| # | Business Question |
|---|---|
| 1 | Revenue generated by male vs. female customers |
| 2 | Discount users who still spent above the average purchase amount |
| 3 | Top 5 products by average review rating |
| 4 | Average spend: Standard vs. Express shipping |
| 5 | Do subscribers spend more than non-subscribers? |
| 6 | Top 5 products with the highest discount rate |
| 7 | Customer segmentation: New, Returning and Loyal |
| 8 | Top 3 most purchased products in each category |
| 9 | Are repeat buyers more likely to subscribe? |
| 10 | Revenue contribution by age group |

###  Power BI Dashboard
An interactive dashboard (`customer_behavior_dashboard.pbix`) that visualises:
- Total revenue, customer count and average spend
- Revenue by category, gender and age group
- Customer segments (New / Returning / Loyal)
- Product performance, ratings and discount usage
- Subscription and shipping behaviour

## How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
   ```
2. **Install dependencies**
   ```bash
   pip install pandas sqlalchemy psycopg2-binary jupyter
   ```
3. **Set up PostgreSQL**: create a database named `customer_behavior`
4. **Run the notebook**: open `code.ipynb`, update the CSV path and set your database credentials (use environment variables, never hard-code passwords)
5. **Run the SQL**: open `customer_sql_queries.sql` in pgAdmin or DBeaver and run the queries against the `customer` table
6. **Open the dashboard**: open the `.pbix` file in Power BI Desktop
